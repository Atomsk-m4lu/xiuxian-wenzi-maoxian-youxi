# 修仙：逆命

一个单文件的修仙文字冒险游戏。无依赖、无构建、无后端 —— 双击 `index.html` 就能玩，手机浏览器同样适配。

## 玩法

从青石村测灵根开始，你是一个五灵根废材。八个场景、五个结局，每一步都要拿命换：

- **状态**：境界 / 修为 / 灵石 / 道心 / 寿元 / 伤势 —— 寿元燃尽则坐化，伤势满百则身死，道心散尽则堕魔。
- **六属性**：开局择身，把二十点分到臂力（战斗）、敏捷（先手闪避）、根骨（气血防御）、悟性（修炼领悟）、运气（机缘随机）、毅力（心魔突破）。
- **天赋**：分点后从十种天赋里认下一种，只在对应判定与战斗里真实生效。
- **闭关**：修为满可冲击境界，破关延寿；也可苦修、纳灵石、闭关疗伤 —— 都要拿寿元换。
- **人物**：路上会遇到四位有独立出身、门派、喜好与忌讳的角色。关系从陌生到道侣，也可能走到敌对与决战；好感 20 / 50 / 80 各有专属剧情，满值另有结局。
- **世界观**：名门正派、中立门派、邪魔歪道，超一流到散修；天 / 地 / 玄 / 黄四阶功法，各配一项属性。
- **隐藏**：有一个人人都会路过、但多数人不会走进去的路口。

## 操作

- 选项即剧情分支，底部常驻「闭关苦修 / 纳灵石 / 闭关疗伤 / 人物 / 存档 / 重开一世」。
- 进度自动存在浏览器 localStorage，换设备不同步。

## 说明

纯 HTML + CSS + 原生 JS 单文件，未使用任何框架与外部资源。
